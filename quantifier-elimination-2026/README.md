# Элиминация кванторов

Решите задания из [tasks.md](tasks.md) и запишите ответы в [tasks.py](tasks.py). Каждая функция получает параметры Z3 и возвращает одну бескванторную формулу `BoolRef`. Реализовывать общий алгоритм элиминации не нужно.

Для конъюнкции и дизъюнкции используйте `And(...)` и `Or(...)`, для отрицания — `Not(...)`. Чтение массива записывается как `A[i]` или `Select(A, i)`, делимость — как `term % divisor == 0`.
