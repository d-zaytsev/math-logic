# py-sat-reductions

Задачи на сведение в SAT. Задачи состоят в реализации функций, в которых на данный момент стоит `raise NotImplementedError()`.

Подразумевается, что каждую задачу вы будете сводить в SAT и решать вызовом SAT-решателя. Поэтому если задача решена как-то иначе, она засчитана не будет.
