# coq-fp-intro

Работоспособность проверялась на Coq 8.20

Для работы рекомендуется использовать расширение для vscode: [vscoq](https://marketplace.visualstudio.com/items?itemName=maximedenes.vscoq)

Задачи приводятся в комментариях `(* Exercise *)`. Каждая задача состоит либо в том, чтобы написать или дополнить код, либо в том, чтобы доказать теорему. При решении можно использовать уже доказанные теоремы и существующие функции и типы.

Всего за задание можно получить **10** баллов.

Порядок решения задач:

- реализовать недостающие функции и заменить `Admitted` на доказательства в файле [FPIntro.v](FPIntro.v);
