# chc-reductions

Сведение задач верификации к дизъюнктам Хорна с ограничениями (CHC) и решение их с помощью Spacer (Z3).

## Задачи

| № | Что | Баллы |
|---|---|---:|
| 1 | Цикл `double`: `x >= 0 → double(x) = 2x` | 1 |
| 2 | Функция Аккермана: `m, n >= 0 → ack(m, n) >= n` | 2 |
| 3 | Поиск в массиве: корректность результата | 3 |
| 4 | `recursive_simple`: слабейшее предусловие отсутствия исключения | 4 |
